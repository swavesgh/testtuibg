# AutoHit (Fabric, Minecraft 26.2)

Client-side mod. Attacks the entity under your crosshair once it is within reach.

Build (JDK 25 + Gradle 9.3+):
    gradle wrapper
    ./gradlew build
Jar: build/libs/autohit-1.0.0.jar  (needs Fabric Loader 0.19.3+ and Fabric API for 26.2)

Keys (rebindable in Controls): R = toggle, Right Shift = settings.
Settings tabs: General, Combat (prefer crits, avoid sweeps, max extra delay), Ghost Hits, Focus.
Config file: config/autohit.json

NOTE: Auto-attack is banned on most multiplayer servers. Use only where allowed.
